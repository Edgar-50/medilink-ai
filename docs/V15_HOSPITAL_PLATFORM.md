# MediLink v15 — Hospital Platform

- Multi-facility data model.
- Bed and ward command board.
- Staff roster / shift model.
- Cross-facility referral queue.
- Governance export records.
- Expanded admin care-network workspace.
- Tenant-ready direction for future facility-scoped RBAC.

This release completes the v12-v15 architecture path while keeping the existing patient, clinician, AI, telehealth and IoT features.
